# Validate the five real simulation cases

uwvm2-ros runs the application/ROS layer. Official native drivers, virtual
controllers, simulators, physics/rendering engines and their base dependencies
may remain external endpoints. Pin their actual roles, versions, models,
licenses and interfaces; their Wasm port is not required. Application ROS calls,
control/planning decisions, callbacks and state/feedback processing must run in
real Wasm through exact VM authority. Native code may not perform those tasks
under an environment label. The [joint observation capacity contract](performance/observation-capacity.en_US.md)
separately covers complete types, event ledgers, full run phases and disk budgets.

The following are required cases, not completed-scene claims. Label an original
application port and a newly developed complete real SDK case separately. A new
real case is valid work; it is not retroactive evidence of an upstream port.
