# 便携导航和传感器输入契约0.3.0

本版本为可评审候选，通用七调用ABI仍为版本1。主机能力、权限及原生结果确认须
独立实现与验收。实际编译和结构检查由单独产物凭据报告，不能替代VM、原生ROS
或官方仿真验收。

导航采用48/49/50三种描述/状态/命令记录。位置为整数毫米，角度为每圈恰好
6283186个刻度，正负半圈端点表示同一朝向。原生弧度换算、坐标变换、地图/里程计
身份及限位全部外置，避免将取整后的十进制圈长当作2*pi弧度。旧0.2.0的16/17/18
毫弧度记录保持原样，不能冒充新版记录。算法只计算一次有界目标，并要求原生终态
成功及新鲜位姿；不实现平衡、步态、力矩或三维控制。

传感器算法读取实际mono8/RGB8载荷（含行填充），验证尺寸和步幅，在Wasm内计算
FNV-1a-32，并输出epoch、采样序号、帧身份、编码及尺寸。ROS2 Header没有序号
字段，适配器应分配递增接收序号，另存原生时间戳。最终验收必须证明官方模拟器
经ROS Image、授权VM内存进入正在执行的Wasm，独立核对原生采样与实际输入拷贝
SHA256并复算FNV。源码包、回放、echo及适配器预计算摘要不能替代该链路。
FNV不是密码学认证，也不是视觉检测算法。

contract.json、wire.json、adapter.schema.json和algorithms.json定义本版本。
适配JSON须严格限制UTF8、长度、重复及未知键，按完整原字节计算身份，与策略和
Wasm摘要分开。资源、坐标/标定/单位映射和显式权限均位于Wasm外。缺少依赖或
不兼容原生语义须保持阻塞，不能标记通过或不适用。仅允许软件仿真，禁止实体操作。

在准入的SSH Linux进程内，设置UWVM_ROS_SDK_ROOT为精确暂存SDK，进入对应示例，
沿唯一现有Xmake C/LLVM23路径运行xmake f -y -c -a wasm32及xmake -vD -j2。
每个实际产物冻结完整SHA256后，在适用平台直接复用相同字节。已有4449字节关节
产物保持不变。实际VM仍强制checked生成链/崩溃栈、来源及权限校验，无公开unwind开关。
