This public application consumes GraphNameSnapshot and the existing shared Codecs.STRING wire format. Endpoint functions carry bounded scalar values, with a positive even revision around a completed snapshot. The receiver owns its copied byte array and rejects changed revisions/extents, out-of-range bytes, incomplete values, malformed UTF-8 and noncanonical graph names. Mutating a source or an exported copy cannot alter a retained snapshot.

Ordinary Xmake builds four genuine Java AOT outputs. SnapshotChecks executes local copy/decoder assertions inside Wasm. It has no ROS operation or private-instance acceptance. The two-instance graph consists of name-endpoint as heap_a plus name-copy-consumer. The three-instance graph instantiates the same exact endpoint bytes twice as heap_a/heap_b and runs alias-name-consumer. The latter also requests bounded allocation in A and checks B's logical value again.

Application scalar functions create no VM ABI, grant or authority. Logical values and declared unshared memories alone do not prove isolation. The ordinary shared-preload dependency path is not selected for these independent graphs. All six original isolation groups and all four true ROS service scenarios remain required.
