# GNU R / fourier / stand_pose

This source uses the original complete R codecs and statically registered `.Call` functions. Pass one explicitly granted alias and a positive exact decimal sequence. Services run once; topic polls have a finite budget. Cleanup precedes output. The genuine GNU R 4.5.1 standalone VM still requires the complete Fortran90 numerical closure, embedded base-package filesystem and nonlocal-control qualification. See `share/language/r/PORTING.md`; this is source work, not a runnable interpreter claim.
