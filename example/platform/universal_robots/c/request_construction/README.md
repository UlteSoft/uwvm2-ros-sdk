# UR request construction in a real Wasm guest

Build the three targets with the installed native SDK and run the standard Xmake guest-component tests. Product builds and execution must run on SSH Linux under the current VM-owner control entry and this exact subject's own lifecycle qualification. The shared public test entry requires its real VM boundary and pinned runtime deployment. Missing admission remains a visible failed/blocked test.

Each target selects its exact original provider catalog. ROS1/ROS2 ur_msgs uses a scalar Analog data record with state; the fixed PolyScopeX urinterfaces commit uses array data and Analog.value. The older SDK-v0.11 scalar API is a distinct version. No physical unit conversion, implicit node/client, host business implementation or permission grant occurs.

The construct case checks real request fields and canonical encoding; invalid checks non-finite values, invalid enum/range/capacity/null inputs and unchanged whole output bytes; alias checks staged self-copy, duplicates, empty array clearing and scalar boundaries. These are local value assertions in Wasm. They are not service roundtrips, runtime permission negatives, independent-memory tests, Stage A or Stage B.
