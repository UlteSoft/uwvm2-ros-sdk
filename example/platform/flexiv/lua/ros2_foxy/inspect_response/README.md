# flexiv ros2_foxy lua inspect_response

This genuine lua program reads at most 2 runtime input bytes and validates every original field of `flexiv_msgs/msg/Mode`.
The complete source-language codec produces its output during execution; no expected result is embedded.
This is a bounded codec application. Native service/action completion requires a separate qualified peer flow.
Set `UWVM_ROS_SDK_ROOT` and build with this directory's `xmake.lua`; deployment is one `.wasm`.
The shared language adapter, its full compiler/VM/AOT closure, and the selected target ABI must be installed and qualified.
