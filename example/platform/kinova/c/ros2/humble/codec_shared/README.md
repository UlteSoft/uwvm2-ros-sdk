# Complete original Kinova FJT component library

Build with `xmake f --arch=wasm32` or `wasm64`, then `xmake`. Use the installed SDK through `UWVM_ROS_SDK_ROOT`. Select `goal`, `feedback` or `result` and supply complete original canonical hexadecimal bytes in the manual deployment arguments. The ordinary shared target owns the complete decoded component and output memory. Six scalar exports transfer bytes, extents and the component selector. The actual eager constructor must run before main.

The complete catalog retains17 records and64 fields; this example consumes the complete FJT closure of16 records and59 fields, including both trajectory families, component tolerance arrays, every feedback branch and the original result code/text. Decode errors retain22. Main and shared library explicitly disable ROS and request no additional WASI rights; ordinary standard streams remain available. This validates source-language compilation and library interoperation. Exact Humble native ROS delivery still requires its genuine selected SDK and native identity; none is invented or inferred from Jazzy.
